# 王兴 · 人物时间线

## 完整时间线

| 时间 | 事件 |
|------|------|
| 1979年2月 | 出生于福建龙岩，父亲王苗是当地知名企业家（水泥厂） |
| 1997年 | 考入清华大学电子工程系 |
| 2001年 | 本科毕业，赴美国特拉华大学攻读电子与计算机工程博士 |
| 2003年11月 | 给大学室友王慧文打越洋电话，"美国这边SNS很火" |
| 2004年初 | 辍学回国创业，王慧文从中科院退学，与赖斌强三人集资30万 |
| 2004年 | 创办"多多友"、"游子图"社交项目，均失败 |
| 2005年秋 | 受Facebook启发，创办校内网 |
| 2006年 | 校内网用户暴增但资金不足，以200万美元卖给陈一舟（后改名人人网） |
| 2007年5月 | 创办饭否网（中国微博鼻祖，类Twitter） |
| 2007年 | 张一鸣加入饭否担任技术合伙人（后离开） |
| 2009年7月7日 | 饭否被关闭（内容审查政策原因） |
| 2010年3月 | 创办美团网，选中Groupon团购模式（"四纵三横"分析法） |
| 2010年11月 | 饭否重新开放 |
| 2010-2011年 | "千团大战"，5000多家团购网站混战 |
| 2011年 | 挖来阿里铁军干嘉伟任COO，建立线下地推体系 |
| 2012年 | 千团大战尾声，美团从5000家中胜出 |
| 2013年 | 美团启动外卖业务 |
| 2015年10月 | 美团与大众点评合并，成立"美团点评" |
| 2015年后 | 逐步脱离阿里体系，转投腾讯阵营 |
| 2016年 | 提出"互联网下半场"概念，乌镇与张一鸣、程维三人对话 |
| 2017年 | 秘密启动美团打车业务 |
| 2017年 | 提出"上天、入地、全球化"三大方向 |
| 2018年4月 | 27亿美元收购摩拜单车 |
| 2018年9月 | 美团在香港联交所上市（IPO），发布"Food+超级平台"战略 |
| 2018年起 | 与阿里在本地生活领域全面竞争（阿里全资收购饿了么） |
| 2020年9月 | "外卖骑手困在系统里"争议，美团承诺增加弹性时间 |
| 2021年 | 美团因"二选一"被反垄断调查，最终被罚34亿元 |
| 2023年 | 美团更名去掉"点评"，统一品牌为"美团" |
| 2024年 | 美团持续扩展新业务：社区团购（美团优选）、即时零售（美团闪购） |
