# Peter Thiel · 人物时间线

> 调研时间：2026-04-12

## 完整时间线

| 时间 | 事件 | 意义 |
|------|------|------|
| 1967.10.11 | 出生于西德法兰克福 | 德裔美国人背景 |
| 1968 | 随家人移民美国，定居俄亥俄州克利夫兰 | 父亲为化学工程师 |
| ~1980s | 少年时期，全美国际象棋高排名选手 | 战略博弈思维的早期塑造 |
| 1985-1989 | 斯坦福大学哲学本科 | 师从 René Girard，接触模仿理论 |
| 1987 | 创办 The Stanford Review（保守派校报），任首任主编 | 早期逆向思维和媒体实践 |
| 1989-1992 | 斯坦福法学院，获 JD 学位 | 法律训练塑造了精确论证风格 |
| 1992-1993 | 在联邦上诉法院做书记员 | 短暂法律职业经历 |
| 1993-1996 | 在 Sullivan & Cromwell 做衍生品交易律师 | 金融领域初步接触 |
| 1995 | 与 David Sacks 合著《The Diversity Myth》 | 对多元文化主义的系统批判 |
| 1996 | 创立 Thiel Capital Management | 首次进入投资领域 |
| 1998.12 | 与 Max Levchin 共同创立 Confinity | PayPal 的前身 |
| 1999 | Confinity 推出 PayPal | 数字支付革命开始 |
| 2000 | Confinity 与 X.com（Elon Musk）合并 | PayPal Mafia 形成 |
| 2000-2002 | 担任 PayPal CEO | 领导公司度过泡沫破裂 |
| 2002.07 | eBay 以15亿美元收购 PayPal | Thiel 个人获得约5500万美元 |
| 2003.05 | 创立 Palantir Technologies | 将 PayPal 反欺诈技术扩展到情报领域 |
| 2004 | 发表《The Straussian Moment》 | 对后9/11政治哲学的深度思考 |
| 2004.08 | 投资 Facebook 50万美元（10.2%股份） | 史上最成功的天使投资之一 |
| 2005 | 与 Ken Howery、Luke Nosek 创立 Founders Fund | 顶级风投基金 |
| 2007 | Gawker 公开 Thiel 的同性恋身份 | 为后来的法律战种下种子 |
| 2011 | 创立 Thiel Fellowship | 反大学运动的标志性举措 |
| 2011 | 在 Yale Law School 演讲，结识 JD Vance | 未来政治联盟的起点 |
| 2012 春 | 在斯坦福教授 CS183 课程 | Blake Masters 笔记后成为《Zero to One》 |
| 2012.05 | Facebook IPO 后出售大量股份 | 获利约4亿美元 |
| 2014 | 出版《Zero to One》 | #1 NYT 畅销书，全球销量超250万 |
| 2014 | WSJ 发表 "Competition Is for Losers" | 核心思想的媒体传播 |
| 2015.11 | René Girard 去世，Thiel 在追悼会上发言 | 失去最重要的知识导师 |
| 2016.07 | 在共和党大会为 Trump 站台演讲 | 硅谷唯一公开支持 Trump 的顶级人物 |
| 2016.05 | 被揭露秘密资助 Gawker 诉讼9年 | 投入约1000万美元 |
| 2016.06 | Hulk Hogan 胜诉，Gawker 关闭 | 最具争议的个人战役 |
| 2018.01 | 与 Reid Hoffman 在斯坦福公开辩论 | Cardinal Conversations：科技与政治 |
| 2019 | 作为 Eric Weinstein The Portal 播客首期嘉宾 | 讨论技术停滞与制度虚伪 |
| 2020 | 未资助 Trump 连任竞选 | 判断 COVID 使连任无望 |
| 2021.02 | 带 JD Vance 首次见 Trump | Mar-a-Lago 会面 |
| 2021 | Max Chafkin 出版传记《The Contrarian》 | 对 Thiel 权力的批评性审视 |
| 2022 | 向 Vance 俄亥俄参议员竞选捐赠1500万美元 | 史上最大单一参议员候选人捐款 |
| 2024 | 推动 Trump 选择 Vance 为副总统候选人 | 电话游说 Trump |
| 2024 | 表示会投票给 Trump 但不捐款 | 策略性距离保持 |
