# Reid Hoffman - 关键决策

## 1. 从学术到科技的转型
- Oxford哲学硕士毕业后，没有走学术路线
- 想做"transcendental anthropology"——用哲学分析人类行为
- 意识到"如果想影响更多人，科技是更有效的杠杆"
- 1994年加入Apple，参与eWorld（早期社交网络尝试）
- **决策逻辑**：哲学训练+科技杠杆>纯学术影响力

## 2. SocialNet创业失败（1997-1999）
- 联合创始人，聚焦在线约会和兴趣匹配
- 承认当时缺乏商业管理经验
- 被迫放弃项目
- **教训**：第一次创业的失败为后续提供了关键经验——"embarrassed by v1"的理念可能源于此

## 3. 加入PayPal（2000-2002）
- 作为执行副总裁，负责所有外部关系
- 与Peter Thiel、Elon Musk、Max Levchin共事——"PayPal Mafia"成员
- 帮助塑造PayPal的病毒式用户获取策略
- 推动与Intuit、Visa、MasterCard、Wells Fargo的合作
- 为eBay收购PayPal发挥关键作用
- **决策逻辑**：在网络效应的支付平台中学习规模化

## 4. 创建LinkedIn（2002-2016）
- 2002年12月在PayPal期间就开始筹备
- 与SocialNet和PayPal的前同事联合创始（Allen Blue等）
- 2003年5月5日上线，最早的商务社交网络之一
- **关键假设**：专业人士需要一个网络来管理职业关系——工作和职业是重要到足以支撑一个独立社交网络的领域
- 2011年IPO，Hoffman持股价值约23.4亿美元
- **决策逻辑**：网络效应 + 专业领域 + 先发优势

## 5. LinkedIn卖给Microsoft（2016）
- 2016年6月13日，Microsoft以262亿美元现金收购
- Hoffman的理由："Microsoft是LinkedIn的天然合作伙伴"
- 认为这是"为股东、客户和员工创造价值的最佳方式"
- 2017年3月14日成为Microsoft董事会成员
- **决策逻辑**：
  - Microsoft的企业客户基础+LinkedIn的专业网络=协同效应
  - 独立运营面临的竞争压力（Facebook等）
  - 现金交易的确定性>继续独立的不确定性
  - 这体现了"判断何时blitzscale，何时被收购"的战略判断

## 6. Greylock Partners投资策略（2009至今）
- 2009年加入，2010年成为合伙人
- 聚焦：能触达数亿用户的早期消费产品
- 核心投资标准：网络效应、规模化潜力
- AI投资：截至2023年，Hoffman和Greylock投资了至少37家AI公司
- 2023年8月宣布不再担任普通合伙人，转为风险合伙人
- **决策逻辑**：用网络效应思维筛选投资——有网络效应的企业才值得blitzscale

## 7. AI投资布局
### OpenAI
- 2016年作为首批捐赠者之一，当时还是非营利组织
- 与Sam Altman、Elon Musk等共同建立
- 后来OpenAI转型为利润上限公司

### Inflection AI（2022-2024）
- 与Mustafa Suleyman（DeepMind联合创始人）和Karén Simonyan联合创立
- 2023年6月融资13亿美元，估值40亿美元
- 开发Pi——聚焦情感支持和对话的AI聊天机器人
- 2024年3月：Microsoft以约6.5亿美元"许可"Inflection技术，雇走大部分员工
- **决策争议**：作为Inflection联合创始人+Microsoft董事的双重身份
- Hoffman在LinkedIn保证"所有投资者会有好结果"

### Manas AI（2025）
- 与癌症研究者Siddhartha Mukherjee联合创立
- 2450万美元种子轮（General Catalyst和Hoffman领投）
- 聚焦AI驱动的抗癌药物发现
- 与Microsoft合作进行分子对接计算
- **决策逻辑**：AI+医疗=下一个superagency应用场景

### Anthropic
- 通过Greylock投资
- 2025年10月Hoffman在X上披露"Greylock是Anthropic的投资者"

## 8. 政治参与
- 过去十年向民主党候选人、州党部、超级PAC、倡导团体捐款数千万美元
- Biden 2020竞选捐款超100万美元
- 2018年为Alabama选举中反Roy Moore的虚假信息行动提供资金，后道歉
- 2026年1月发表文章呼吁硅谷反对Trump政府
- **决策逻辑**：认为科技领袖有责任参与公共事务——"Silicon Valley can't be neutral any longer"

## 决策模式总结
1. **网络效应优先**：几乎所有重大决策都围绕"这有没有网络效应？"
2. **速度vs确定性的权衡**：知道何时blitzscale（LinkedIn增长期），何时套现（卖给Microsoft）
3. **ABZ规划的实践**：从哲学→Apple→SocialNet(失败)→PayPal→LinkedIn，每次都有fallback
4. **"And"思维**：投资者AND创始人，民主党人AND批评民主党，AI乐观派AND承认风险
5. **网络as杠杆**：用人际网络创造投资机会和影响力
