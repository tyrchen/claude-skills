# Richard Feynman — 时间线

## 完整时间线

| 年份 | 事件 | 意义 |
|------|------|------|
| 1918 | 出生于纽约Far Rockaway | 犹太中产家庭，父亲Melville是制服推销员但热爱科学 |
| 1935-39 | MIT本科 | 物理学学士，早期展现计算天赋 |
| 1939-42 | Princeton博士（导师John Wheeler） | Wheeler-Feynman吸收理论，最小作用量原理的新理解 |
| 1942 | 与高中恋人Arline Greenbaum结婚 | Arline已患肺结核，费曼明知仍然结婚 |
| 1943-45 | 曼哈顿计划（洛斯阿拉莫斯） | 领导理论计算组，撬保险箱，打邦戈鼓，见证核爆 |
| 1945 | Arline去世 | 深刻影响费曼的情感世界，战后抑郁期开始 |
| 1945-50 | Cornell教职 | 战后重建研究动力，旋转盘子→重新点燃对物理的兴趣 |
| 1948 | 费曼图、路径积分 | 量子电动力学的革命性新方法 |
| 1950 | 转入Caltech | 此后终身在Caltech，直至去世 |
| 1959 | "There's Plenty of Room at the Bottom" | 纳米技术概念的先驱演讲 |
| 1960 | 与Gweneth Howarth结婚 | 第三任妻子（第二任婚姻仅4年），稳定的家庭生活 |
| 1961-64 | 费曼物理学讲义 | 被认为20世纪最伟大的物理学教材 |
| 1965 | 诺贝尔物理学奖 | 与Schwinger、朝永振一郎共享，因QED贡献 |
| 1974 | Cargo Cult Science演讲 | 加州理工毕业典礼，定义科学诚信的标准 |
| 1978 | 首次癌症手术 | 腹部肿瘤，此后与癌症斗争十年 |
| 1981 | BBC "The Pleasure of Finding Things Out" | 最著名的电视访谈 |
| 1985 | 出版两本书 | 《别闹了，费曼先生》和《QED》，成为公众知识分子 |
| 1986 | 挑战者号调查 | O型圈演示，Appendix F，"nature cannot be fooled" |
| 1988.2.15 | 去世，享年69岁 | 遗言："I'd hate to die twice. It's so boring." |

## 关键关系

- **Arline Greenbaum**：高中恋人、第一任妻子，患肺结核去世。费曼对她的感情深刻影响了他对生命和不确定性的态度。
- **Gweneth Howarth**：第三任妻子，英国人，提供了稳定的家庭环境。
- **John Wheeler**：Princeton博士导师，合作吸收理论。
- **Freeman Dyson**：将费曼图推广至主流物理学界。
- **Murray Gell-Mann**：Caltech同事和竞争者，关系复杂。
- **Hans Bethe**：曼哈顿计划上级，终身朋友。
- **Joan Feynman**：妹妹，天体物理学家，费曼鼓励她从事科学。

## 演化轨迹

1. **神童期 (1918-1939)**：Far Rockaway的自学天才→MIT→Princeton
2. **理论物理新星 (1939-1945)**：Wheeler的学生→曼哈顿计划的年轻领袖
3. **战后抑郁与重生 (1945-1948)**：Arline去世→Cornell的低谷期→旋转盘子重燃兴趣
4. **QED革命者 (1948-1965)**：费曼图→路径积分→诺贝尔奖
5. **伟大教育者 (1961-1985)**：物理学讲义→公众科普→两本畅销书
6. **公众知识分子与科学良心 (1985-1988)**：挑战者号调查→成为科学诚信的象征
