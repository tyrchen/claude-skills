# 马化腾 — 人物时间线

> 调研时间：2026-04-12

## 完整时间线

### 早年（1971-1993）

| 时间 | 事件 | 意义 |
|------|------|------|
| 1971年10月29日 | 出生于海南省东方县（今东方市） | - |
| 1984年 | 随家庭从海南迁居深圳 | 深圳经济特区的成长环境塑造了他的市场意识 |
| 1989年 | 考入深圳大学计算机系 | 工程师基因的起点 |
| 1993年 | 深圳大学计算机系毕业 | - |

### 润迅时期（1993-1998）

| 时间 | 事件 | 意义 |
|------|------|------|
| 1993年 | 加入润迅通讯发展有限公司 | 从软件工程师做到开发主管 |
| 1993-1998年 | 专注寻呼软件开发 | 积累了通讯行业经验，理解"连接"的价值 |
| ~1997年 | 接触ICQ，看到即时通讯的潜力 | 创业想法的萌芽 |

### 腾讯创立与生存期（1998-2004）

| 时间 | 事件 | 意义 |
|------|------|------|
| 1998年11月 | 与张志东、许晨晔、陈一丹、曾李青共同创立腾讯 | 五人创始团队，名片上只印"工程师" |
| 1999年2月 | 推出OICQ（后改名QQ） | 模仿ICQ，但针对中国用户做了大量本地化改进 |
| 1999年 | OICQ用户达100万，但公司只剩1万美元现金 | 用户增长与资金枯竭的矛盾——差点60万卖掉 |
| 1999年11月 | 深圳高交会获IDG和盈科数码220万美元投资 | 生死融资，公司存活下来 |
| 2001年 | 南非MIH(Naspers)入股腾讯 | 后来成为腾讯最大的机构股东 |
| 2003年 | 推出QQ秀（虚拟形象付费） | 找到盈利模式——虚拟增值服务，腾讯to C基因确立 |
| 2004年6月 | 腾讯在港交所上市（股票代码0700） | 发行价3.7港元，马化腾任董事会主席兼CEO |

### 多元扩张期（2004-2010）

| 时间 | 事件 | 意义 |
|------|------|------|
| 2005年 | 推出QQ空间 | 社交网络布局，内部赛马机制的产物 |
| 2006年 | 推出QQ游戏平台 | 游戏业务开始成为核心收入来源 |
| 2008年 | 腾讯市值突破100亿美元 | 成为中国互联网三巨头之一（BAT） |
| 2009年 | 推出QQ农场等社交游戏 | 社交游戏时代的巅峰 |

### 3Q大战与开放转型（2010-2013）

| 时间 | 事件 | 意义 |
|------|------|------|
| 2010年9-11月 | 3Q大战爆发 | 360推出"扣扣保镖"，腾讯发布"艰难的决定"要求用户二选一 |
| 2010年10月 | 张小龙深夜邮件建议做移动社交 | 马化腾秒回"马上就做"，微信项目启动 |
| 2011年1月 | 微信1.0版本上线 | 张小龙团队仅用约2个月开发 |
| 2011年6月 | 腾讯举办首届开放大会 | 宣布开放平台战略，分享100亿收入给合作伙伴 |
| 2012年3月 | 微信用户突破1亿 | 距离立项仅16个月 |
| 2013年 | 马化腾首次当选全国人大代表 | 开始在政策层面发挥影响力 |

### 微信时代与投资帝国（2013-2018）

| 时间 | 事件 | 意义 |
|------|------|------|
| 2014年1月 | 微信红包上线 | 微信支付爆发式增长的起点 |
| 2014年3月 | 入股京东（15%） | "半条命交给合作伙伴"的开始，退出电商自营 |
| 2015年 | 出版《互联网+：国家战略行动路线图》 | 系统阐述"互联网+"和"连接一切"理念 |
| 2016年 | 86亿美元收购Supercell | 游戏行业最大并购，全球化布局里程碑 |
| 2017年 | 腾讯市值超过阿里巴巴，马化腾成为中国首富 | 腾讯市值突破5000亿美元 |
| 2017年 | 微信小程序上线 | 微信生态平台化的关键一步 |
| 2018年 | 马化腾连任十三届全国人大代表 | - |

### 产业互联网转型（2018-2021）

| 时间 | 事件 | 意义 |
|------|------|------|
| 2018年9月 | 腾讯第三次战略升级 | 成立CSIG，从消费互联网转向产业互联网 |
| 2018年 | 腾讯股价从475港元跌至250港元左右 | "没有梦想的腾讯"质疑声四起 |
| 2019年 | 推出腾讯会议等ToB产品 | 产业互联网战略落地 |
| 2020年 | 新冠疫情期间微信生态价值凸显 | 健康码、在线教育、远程办公全面爆发 |
| 2021年 | 中国加强科技平台监管 | 游戏限制+反垄断审查双重压力 |

### 调整与重塑期（2021-2024）

| 时间 | 事件 | 意义 |
|------|------|------|
| 2021年8月 | 未成年人游戏时长限制政策出台 | 游戏业务面临重大政策调整 |
| 2021年12月 | 减持京东股份（17%→2.3%） | 以派发股息方式退出大股东地位 |
| 2022年 | 一年内六次减持投资组合，共1300亿元 | 回应监管+战略调整 |
| 2022年11月 | 分派美团股份给腾讯股东 | 继续"瘦身"投资组合 |
| 2022年底 | 内部讲话罕见强硬 | "降本增效要成为习惯""该砍就砍" |
| 2023年 | 腾讯宣布"筑底反弹" | 业绩企稳回升 |
| 2024年1月 | 年会讲话风格转为"走心务实" | 强调产品热爱和一线穿透 |
| 2024年Q4 | 资本开支同比增长386%至365.8亿元 | AI战略全面加速 |

### AI时代（2025-至今）

| 时间 | 事件 | 意义 |
|------|------|------|
| 2025年1月 | 内部讲话宣布全面拥抱AI | 微信、QQ等产品将推出AI智能体 |
| 2025年初 | 重组AI团队 | 加大原生AI产品研发和营销力度 |
| 2025年初 | 美国国防部将腾讯列为"中国军事公司" | 腾讯公开否认，国际化挑战加剧 |
| 2025年 | 积极拥抱DeepSeek | "自研+开源"双核AI策略 |
| 2025年Q1 | 单季度ToB营收549亿元 | AI+云业务高速增长 |
| 2025年 | 预计全年资本开支接近千亿级 | 研发投入创历史新高 |

## 最近12个月动态（2025年4月-2026年4月）

- 腾讯AI战略持续加速，混元大模型能力迭代
- 微信AI智能体生态逐步形成
- 2024年全年研发投入706.9亿元，2018年至今累计3403亿元
- 腾讯2025年Q1财报表现强劲，AI赋能广告和云业务增长
- 国际化策略调整：游戏投资重心从美国转向欧洲和亚洲
- 与DeepSeek的合作深化
