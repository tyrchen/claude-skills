# 01 - 著作与核心术语

## Incerto 五部曲

1. **Fooled by Randomness** (2001) — 随机性欺骗：人类系统性低估运气、高估技能
2. **The Black Swan** (2007) — 极端不可预测事件主导历史，传统模型失效
3. **The Bed of Procrustes** (2010) — 格言集，浓缩哲学观点
4. **Antifragile** (2012) — 超越韧性：从波动/混乱/压力中获益的系统特性
5. **Skin in the Game** (2018) — 对称风险：决策者必须承受后果，否则系统必然腐败

- **Statistical Consequences of Fat Tails** (2020，2025第三版) — 肥尾分布下传统统计方法系统性失效的数学证明

## 核心术语体系

| 术语 | 定义 |
|------|------|
| **Antifragile** | 从波动/压力/混乱中获益（不止是韧性） |
| **Black Swan** | 极端不可预测、影响巨大、事后合理化的事件 |
| **Skin in the Game** | 承受自己决策后果的对称性要求 |
| **Lindy Effect** | 非易腐事物存活越久，预期寿命越长 |
| **Via Negativa** | 通过去除有害来改进，而非添加 |
| **Barbell Strategy** | 极保守+极激进，回避中间地带 |
| **IYI (Intellectual Yet Idiot)** | 拥有一阶逻辑但缺乏二阶能力的半知识分子 |
| **Iatrogenics** | 干预造成的伤害大于不干预 |
| **Fat Tails** | 极端事件的概率远超高斯模型预期 |
