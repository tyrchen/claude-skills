# Phase 1 调研Agent模板

> 6个调研维度的完整任务分配与prompt模板

## Agent IO规则

调研Agent直接将结果写入 `personas/[name]/research/0X-xxx.md`。

**前提**：用户的settings.json中已预授权 `~/.claude/skills/council/personas/**` 的写入权限。

## 调研维度总览

| 维度 | 搜索目标 | 提取重点 | 输出文件 | 级别 |
|------|---------|---------|---------|------|
| 1 著作 | 书、长文、论文、newsletter | 反复出现的核心论点（≥3次=真信念）、自创术语、推荐书单 | `01-writings.md` | 核心 |
| 2 对话 | 播客、长视频、AMA、深度采访 | 被追问时的回答方式、即兴类比、改变立场的瞬间 | `02-conversations.md` | 核心 |
| 3 表达 | Twitter/X、微博、即刻、短文 | 高频用词句式、争议立场、幽默方式、公开辩论 | `03-expression-dna.md` | 核心 |
| 4 他者 | 他人分析、书评、批评、传记 | 外部观察到的模式、批评与争议、与同行对比 | `04-external-views.md` | 辅助 |
| 5 决策 | 重大决策、转折点、争议行为 | 决策背景与逻辑、事后反思、言行一致/不一致案例 | `05-decisions.md` | 辅助 |
| 6 时间线 | 出生/出道到现在的完整时间线 | 关键里程碑、思想转折点、**最近12个月动态** | `06-timeline.md` | 辅助 |

### 核心 vs 辅助

- **核心**（1-著作、2-对话、3-表达）：心智模型和表达DNA的主要来源。失败时**重试一次**。
- **辅助**（4-他者、5-决策、6-时间线）：补充视角。失败时**标注缺失，继续推进**。

## 内容标注规则（所有维度通用）

- 注明信息来源和可信度（一手 > 二手 > 推测）
- 区分「他说过的」vs「别人说他的」vs「我推断的」
- 发现矛盾时保留矛盾，不要和稀泥
- 信息源策略遵循 `references/source-policy.md`

## Agent Prompt 模板

每个prompt的**公共尾部**（替换原来的「写入文件」指令）：

```
重要：
- 不要尝试写文件或使用Write工具。将你的调研结果作为文本直接返回。
- 主Agent会负责将你的内容写入对应文件。
- 用markdown格式组织你的输出，以 # [维度名称] 开头。
```

### 维度1: 著作与系统思考

```
你的任务：调研[人名]的著作和系统性长文。

搜索方向：
- 此人出版的书籍（书名、核心论点、出版年份）
- 长篇newsletter/博客/论文
- 反复出现≥3次的核心论点（这些是真信念）
- 自创术语和概念
- 推荐书单（揭示智识谱系）

输出要求：
- 每条信息标注来源URL和可信度
- 区分一手（此人写的）vs 二手（别人总结的）
- 发现矛盾直接记录，不要调和

信息源策略：避免知乎、微信公众号、百度百科。优先使用此人的一手来源（本人著作、个人博客、官方频道）。

将调研结果写入对应的research文件。
```

### 维度2: 长对话与即兴思考

```
你的任务：调研[人名]的播客、长访谈、AMA等对话内容。

搜索方向：
- 深度播客/长视频访谈（>30分钟的优先）
- AMA、问答环节、公开辩论
- 被追问时的回答方式（防守姿态 vs 开放探索）
- 即兴类比和临场发挥
- 改变立场的瞬间（比「一直这样认为」更有信息量）
- 拒绝回答的问题（揭示边界）

输出要求：
- 每条信息标注来源URL、访谈时间和可信度
- 记录此人的对话习惯（打断方式、停顿习惯、追问回应风格）
- 发现矛盾直接记录，不要调和

将调研结果写入对应的research文件。
```

### 维度3: 碎片表达与风格DNA

```
你的任务：调研[人名]的社交媒体、短文、碎片表达。

搜索方向：
- Twitter/X、微博、即刻等社交平台的发言
- 高频用词和句式模式
- 争议立场和激烈表态
- 幽默方式（讽刺/自嘲/荒诞/冷幽默）
- 公开辩论和回怼方式
- emoji/标点符号使用习惯

输出要求：
- 收集≥20条有代表性的原始发言（含原文）
- 统计风格特征：句长、疑问句比例、类比密度、确定性用语
- 标注高频词汇和禁忌词

将调研结果写入对应的research文件。
```

### 维度4: 他者视角与批评

```
你的任务：调研他人对[人名]的评价、分析和批评。

搜索方向：
- 书评、人物传记、深度分析文章
- 同行/竞争对手的评价
- 学术界或专业社区的讨论
- 负面评价和争议事件
- 此人被低估/高估的方面
- 与同行的风格/观点对比

输出要求：
- 每条评价标注来源、评价者身份和可信度
- 平衡正面和负面评价
- 多个来源反复出现的批评需要标注

将调研结果写入对应的research文件。
```

### 维度5: 决策记录与行动

```
你的任务：调研[人名]的重大决策、转折点和争议行为。

搜索方向：
- 职业/事业中的重大决策及理由
- 转折点和关键选择（选了A而非B，为什么）
- 争议行为和事后反思
- 言行一致 vs 言行不一致的案例
- 失败的决策和此人如何处理失败
- 决策风格（快速直觉型 vs 深思熟虑型）

输出要求：
- 每个决策记录：背景、选项、最终选择、理由、结果
- 标注此人事后是否反思过这个决策
- 区分公开声称的理由 vs 实际可能的动机

将调研结果写入对应的research文件。
```

### 维度6: 人物时间线

```
你的任务：整理[人名]从出生/出道到现在的完整时间线。

搜索方向：
- 关键人生/职业里程碑
- 思想转折点（什么时候开始/停止相信某个东西）
- 重要关系（导师、合作者、对手）
- **最近12个月动态**（防止过时）
- 公开身份的变化

输出要求：
- 按时间线格式：| 时间 | 事件 | 对思维的影响 |
- 最近12个月的条目要最详细
- 标注信息来源和可信度

将调研结果写入对应的research文件。
```

## 工具辅助

spawn subagent时可以告知以下工具的存在：

- **字幕下载**：`council download-subtitles <YouTube_URL> --output-dir <目录>`
- **字幕清洗**：`council clean-transcript <input.srt> --output <output.txt>`
- **播客**：搜索transcript网站（podcastnotes.org等）

## 失败处理

| 情况 | 处理 |
|------|------|
| 核心维度超时 | 调整搜索策略后重试一次 |
| 核心维度二次失败 | 标注为「关键信息缺失」 |
| 辅助维度超时 | 标注缺失，继续推进 |
| 信息源匮乏（<10条） | 提醒用户，降低期望 |
| 结果冲突 | 保留矛盾——矛盾本身是有价值的信号 |

**关键规则**：宁可生成一个诚实标注了局限的60分Advisor，也不要生成一个看起来完美但实际上在编造的90分Advisor。
