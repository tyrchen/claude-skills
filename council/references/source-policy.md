# 信息源策略

> 信息源优先级、黑名单、区域策略的完整定义

## 一、信息源优先级

| 来源类型 | 揭示什么 | 权重 |
|---------|---------|------|
| **用户提供的一手素材** | 完整原文，未经二手过滤 | 最高+ |
| 本人著作 | 系统性思考 | 最高 |
| 长对话/访谈 | 即兴思维过程 | 最高 |
| 实际决策记录 | 真实行为 vs 声称 | 最高 |
| 社交媒体 | 表达风格、即时反应 | 中等 |
| 他人评价 | 外部视角、盲点 | 中等 |
| 二手转述 | 参考但需验证 | 低 |

## 二、信息源黑名单（永远排除）

| 平台 | 排除原因 |
|------|---------|
| 知乎 | 洗稿严重、信息失真率高 |
| 微信公众号 | 封闭生态、无法验证、大量二手转述 |
| 百度百科/百度知道 | 信息陈旧且不可靠 |
| 未注明出处的聚合页 | 无法追溯原始来源 |

## 三、区域信息源策略

通用原则：**优先使用人物母语环境中的一手来源**。每个区域都有高质量平台和低质量平台，按以下指引选择。

### 中文世界

**推荐来源**：
- 权威媒体：36氪、极客公园、晚点LatePost、财新、第一财经、虎嗅、少数派、机器之心
- 播客：小宇宙、喜马拉雅（原始音频，非搬运）
- 视频：B站原始视频（本人上传或官方频道，非搬运号）
- 社交：微博（本人认证账号）、即刻
- 书籍：豆瓣读书（书评参考，非正文来源）

**排除来源**：见黑名单

### 英语世界

**推荐来源**：
- 社交：Twitter/X（本人账号）、LinkedIn
- 长内容：Substack、Medium（本人发布）、个人博客
- 视频/播客：YouTube、Spotify、Apple Podcasts
- 书评/分析：Amazon书评、Goodreads
- 媒体：NYT、WSJ、Bloomberg、The Atlantic、Wired、TechCrunch

### 日语世界

**推荐来源**：
- 社交/博客：note.com、はてなブログ（本人账号）、Twitter JP
- 媒体：NewsPicks、日経ビジネス、東洋経済、NHK
- 视频：YouTube JP（本人频道）
- 书籍：Amazon.co.jp 書評

### 韩语世界

**推荐来源**：
- 媒体：朝鮮日報、中央日報、每日經濟
- 博客：Naver Blog（本人认证）、Brunch
- 视频：YouTube KR（本人频道）
- 社交：Twitter KR

### 其他语言/地区

**通用策略**：
1. 搜索该人物母语的主要新闻媒体（Google News + 语言过滤）
2. 检查是否有英文翻译的著作/访谈
3. 查找 Wikipedia 页面的参考文献列表，追溯一手来源
4. 如有TED演讲或国际会议演讲，优先使用（通常有英文字幕）

## 四、本地语料处理

### 本地素材类型与覆盖维度

| 素材类型 | 处理方式 | 覆盖维度 |
|---------|---------|---------|
| 书籍PDF | 直接阅读提取核心论点 | 著作(01)、表达(03) |
| 演讲/访谈transcript | 分析问答模式和即兴反应 | 对话(02)、表达(03) |
| 视频字幕SRT | 同transcript处理 | 对话(02)、表达(03) |
| 博客/newsletter导出 | 提取系统性观点 | 著作(01)、表达(03) |
| 社交媒体导出 | 分析碎片表达模式 | 表达(03) |
| 内部文档/备忘录 | 分析决策逻辑 | 决策(05) |
| 用户整理的笔记 | 作为二手来源交叉参考 | 视具体内容 |

### 本地语料优先模式执行逻辑

1. **先读本地素材**：将用户提供的文件按6个维度分类
2. **识别信息缺口**：本地素材覆盖了哪些维度？哪些维度缺失或薄弱？
3. **定向补充搜索**：只对缺失维度启动网络搜索Agent
4. **来源标记**：调研文件中明确区分「来自用户提供素材」vs「来自网络搜索」

## 五、已安装Skill辅助

Phase 1启动前，**主动扫描 `.claude/skills/` 目录**，检查是否有可用于信息获取的skill：

| 已安装Skill | 用途 | 调用场景 |
|------------|------|---------|
| `gemini-video` | 分析本地视频文件，提取transcript | 用户提供了视频文件但没有字幕 |
| `web-article-reader` | 精确读取网页文章全文 | 找到重要文章URL时，精确提取而非依赖搜索摘要 |
| `agent-reach` | 多渠道信息获取（17个平台） | 需要从X/Reddit/YouTube等平台获取信息 |
| `huashu-research` | 结构化深度调研 | 需要对某个维度做深度调研而非广撒网 |
| `pdf` | 读取PDF书籍/论文 | 用户提供了PDF格式的一手素材 |

在spawn subagent时，把可用skill的名称和用途告知agent，让agent按需调用。
